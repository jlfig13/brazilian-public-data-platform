# Skills

Skills de engenharia do [mattpocock/skills](https://github.com/mattpocock/skills) (MIT),
copiadas como skills de projeto em `.claude/skills/`.

Versão de origem: plugin `mattpocock-skills` v1.2.3.

Para atualizar:

```bash
npx skills@latest update
```

Ou recopiar a partir do repositório de origem.

Comece rodando `/setup-matt-pocock-skills` uma vez neste repositório.
